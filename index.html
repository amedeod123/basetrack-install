BASE Track — Install the App

Watch the 20-second video, then tap your phone type below.
Mira el video y toca el boton de tu telefono.

 iPhone — Install (TestFlight) ▶ Android — Install (Google Play)

After install / Despues de instalar:
1. Tap the tracking link from your dispatch text.
   Toca el link de rastreo de tu texto.
2. Tap Allow While Using App. / Toca Permitir al usar la app.
3. iPhone: go to Settings > BASETrack > Location > Always.
   iPhone: Ajustes > BASETrack > Ubicacion > Siempre.
Android: choose Allow all the time. / Elige Permitir todo el tiempo.
